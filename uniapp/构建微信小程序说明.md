# 构建微信小程序说明

## 方法一：使用自动构建脚本（推荐）

### Windows 系统
1. 双击运行 `build-weixin.bat`
2. 等待编译完成
3. 按照提示在微信开发者工具中导入项目

### Mac/Linux 系统
1. 打开终端，进入项目目录
2. 给脚本添加执行权限：
   ```bash
   chmod +x build-weixin.sh
   ```
3. 运行脚本：
   ```bash
   ./build-weixin.sh
   ```
4. 等待编译完成
5. 按照提示在微信开发者工具中导入项目

## 方法二：手动构建

### 1. 安装依赖
```bash
cd community-canteen-system-uniapp
npm install
```

### 2. 编译项目
```bash
# 开发版本（带热更新）
npm run dev:mp-weixin

# 生产版本（优化后的代码）
npm run build:mp-weixin
```

### 3. 查看编译输出
- 开发版本输出目录：`dist/dev/mp-weixin`
- 生产版本输出目录：`dist/build/mp-weixin`

## 在微信开发者工具中运行

### 1. 打开微信开发者工具
- 如果还没安装，请先下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目
1. 点击"导入项目"或"+"按钮
2. 填写项目信息：
   - 项目名称：社区食堂系统
   - 目录：选择编译输出目录
     - 开发版：`community-canteen-system-uniapp/dist/dev/mp-weixin`
     - 生产版：`community-canteen-system-uniapp/dist/build/mp-weixin`
   - AppID：
     - 如果有正式 AppID，填入即可
     - 如果没有，选择"测试号"或"小程序·云开发"
3. 点击"导入"

### 3. 配置开发环境
1. 点击右上角"详情"
2. 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"
3. 勾选"启用调试"（可选）

### 4. 运行项目
- 点击"编译"按钮或按 `Ctrl+B` (Windows) / `Cmd+B` (Mac)
- 在模拟器中查看运行效果

## 项目配置说明

### manifest.json 配置
```json
{
  "mp-weixin": {
    "appid": "wx23e5e5eb16b6c467",  // 微信小程序 AppID
    "setting": {
      "urlCheck": false  // 开发阶段关闭域名校验
    },
    "usingComponents": true
  }
}
```

### 修改 AppID
1. 打开 `manifest.json`
2. 找到 `mp-weixin.appid`
3. 修改为你的小程序 AppID
4. 重新编译

### API 接口配置
接口地址配置在 `utils/request.js` 中：
```javascript
const baseURL = 'http://127.0.0.1:8080'  // 开发环境
```

**注意**：
- 开发阶段可以使用 HTTP 协议（需要在微信开发者工具中关闭域名校验）
- 生产环境必须使用 HTTPS 协议
- 域名需要在微信公众平台后台配置

## 开发与生产版本的区别

### 开发版本 (dev:mp-weixin)
- 包含 source map，方便调试
- 代码未压缩，可读性好
- 支持热更新
- 文件体积较大
- 适合开发调试

### 生产版本 (build:mp-weixin)
- 代码已压缩和优化
- 移除了调试信息
- 文件体积更小
- 性能更好
- 适合发布上线

## 常见问题

### 1. 编译报错 "Cannot find module"
**解决方案**：
```bash
# 删除 node_modules 和 package-lock.json
rm -rf node_modules package-lock.json

# 重新安装依赖
npm install
```

### 2. 微信开发者工具无法打开项目
**原因**：编译输出目录不正确

**解决方案**：
- 确认选择的是编译输出目录，不是项目根目录
- 开发版：`dist/dev/mp-weixin`
- 生产版：`dist/build/mp-weixin`

### 3. 提示 "不在以下 request 合法域名列表中"
**解决方案**：
1. 在微信开发者工具中点击"详情"
2. 勾选"不校验合法域名"
3. 重新编译

### 4. 页面显示空白
**可能原因**：
- 后端服务未启动
- API 接口地址配置错误
- 页面路径配置错误

**解决方案**：
1. 确认后端服务已启动（http://127.0.0.1:8080）
2. 检查 `utils/request.js` 中的 baseURL 配置
3. 检查 `pages.json` 中的页面路径配置
4. 查看微信开发者工具的控制台错误信息

### 5. 图片无法显示
**可能原因**：
- 图片路径错误
- 图片服务器未启动
- 跨域问题

**解决方案**：
1. 检查图片 URL 是否正确
2. 确认图片服务器已启动
3. 在微信开发者工具中关闭域名校验

## 发布到正式环境

### 1. 修改配置
1. 修改 `utils/request.js` 中的 baseURL 为正式域名（HTTPS）
2. 修改 `manifest.json` 中的 AppID 为正式 AppID
3. 在微信公众平台后台配置合法域名

### 2. 编译生产版本
```bash
npm run build:mp-weixin
```

### 3. 上传代码
1. 在微信开发者工具中打开项目
2. 点击右上角"上传"按钮
3. 填写版本号和项目备注
4. 点击"上传"

### 4. 提交审核
1. 登录微信公众平台：https://mp.weixin.qq.com/
2. 进入"版本管理"
3. 找到刚上传的版本
4. 点击"提交审核"
5. 填写审核信息
6. 等待审核通过

### 5. 发布上线
审核通过后，在"版本管理"中点击"发布"即可上线。
